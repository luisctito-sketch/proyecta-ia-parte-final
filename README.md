## Contenido del módulo

Asistente metodológico para las secciones finales no numeradas del Proyecto de Grado:

1. Referencias bibliográficas.
2. Glosario.
3. Apéndices.
4. Anexos.

## Funciones principales

- Explica el significado y la función de cada sección.
- Control básico de correspondencia cita ↔ referencia por autor/institución y año.
- Orienta la creación automática de bibliografía desde Microsoft Word.
- Incluye modelos básicos APA 6 para libro, artículo, página web, tesis/proyecto y norma.
- Incluye un generador didáctico de referencias básicas.
- Revisa orden y estructura del glosario.
- Clasifica materiales como Apéndice o Anexo según su autoría.
- Revisa inventarios de Apéndices y Anexos y su secuencia A, B, C…
- Genera un prompt experto para revisión semántica en ChatGPT sin inventar datos.

## Regla metodológica central

- **Apéndice**: material creado por el propio estudiante/investigador.
- **Anexo**: material elaborado por terceros y utilizado como respaldo.
